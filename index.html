// FLAGSHIP PROJECT

KORAI Player

A desktop music player that understands your music — not just plays it

Windows macOS* Linux*
Electron Web Audio API Local-First Apache 2.0

KORAI Player is a smart desktop music player that goes beyond simple playback — it analyzes and understands your music. Fully local, no cloud, no tracking, no subscription.

Download for Windows GitHub

Core Features

Format SupportMP3, WAV, FLAC, OGG, M4A
AI AnalysisBPM · Energy · Loudness · Genre
AI RecommenderAudio fingerprint · Similar tracks
Equalizer5-band · 60Hz–14kHz · ±12dB

Modes & Features

Karaoke ModeReal-time vocal removal
Mini-PlayerFloating always-on-top window
Cinema ModeFullscreen + animated vinyl + lyrics
2 Languages / 2 ThemesPersian (RTL) / English · Dark / Glass

Target Audience

  • • Music enthusiasts who prioritize sound quality
  • • Privacy-conscious users (no data sent to cloud)
  • • Large local music libraries needing smart management
  • • Persian speakers needing full RTL support

Technology Stack

Electron (Desktop) + Express (API) + Web Audio API (Audio Processing)

Everything packaged into a single executable — install and run, no extra dependencies.
