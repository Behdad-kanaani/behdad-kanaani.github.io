About Me

KORAI Player

Electron desktop music player · Real-time DSP · Local AI · Privacy-first

Windows macOS* Linux*
Electron Web Audio API Local-First Apache-2.0--Commons--Clause

KORAI Player is a modern desktop music player built with Electron and Node.js. Features real-time DSP (5-band EQ, tempo control, karaoke mode), local AI for BPM/energy analysis, and a cinematic fullscreen vinyl mode. 100% offline — no tracking, no cloud.

Download v1.0 GitHub
